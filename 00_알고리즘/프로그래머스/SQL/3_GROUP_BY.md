## GROUP BY

### 고양이와 개는 몇 마리 있을까

```Oracle
SELECT ANIMAL_TYPE, count(ANIMAL_TYPE) as count FROM ANIMAL_INS GROUP BY ANIMAL_TYPE ORDER BY ANIMAL_TYPE;
```

### 동명 동물 수 찾기

```
SELECT NAME, count(NAME) as count FROM ANIMAL_INS GROUP BY NAME HAVING count(NAME) > 1 ORDER BY NAME;
```

### 입양 시각 구하기(1)

```
SELECT EXTRACT(HOUR FROM CAST(DATETIME AS TIMESTAMP)) AS HOUR, count(DATETIME) AS count 
FROM ANIMAL_OUTS GROUP BY EXTRACT(HOUR FROM CAST(DATETIME AS TIMESTAMP))
HAVING EXTRACT(HOUR FROM CAST(DATETIME AS TIMESTAMP)) BETWEEN 9 AND 19
ORDER BY EXTRACT(HOUR FROM CAST(DATETIME AS TIMESTAMP));
```

select a1.HOUR, NVL(a2.COUNT,0) AS "COUNT"
from (select level-1 as "HOUR"
      from dual 
      connect by level <=24)a1,
