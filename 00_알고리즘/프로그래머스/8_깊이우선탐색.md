## 깊이/너비 우선 탐색

### 타겟 넘버 (1번) 

```java
class Solution {
    static int count = 0;
    static int result = 0;
    static int len;
    static boolean[] visit;
    
    public int solution(int[] numbers, int target) {
        int answer = 0;
        len = numbers.length;
        visit = new boolean[len];
        dfs(numbers, 0, target);
        answer = count;
        return answer;
    } // solution end
    
    private void dfs(int[] numbers, int depth, int target)
    {
        if (depth == len)
        {
            if (result == target)
                count++;
            return;
        }
        if (visit[depth] == false)
        {
            int a = -1;
            for (int i = 0; i < 2; i++)
            {
                result += (numbers[depth] * a);
                visit[depth] = true;
                dfs(numbers, depth + 1, target);
                visit[depth] = false;
                result -= (numbers[depth] * a);
                a *= a;
            }
        }
        
    } // dfs end
}
```

> 다른 사람 코드

```java
class Solution {
    public int solution(int[] numbers, int target) {
        int answer = 0;
        answer = dfs(numbers, 0, 0, target);
        return answer;
    }
    int dfs(int[] numbers, int n, int sum, int target) {
        if(n == numbers.length) {
            if(sum == target) {
                return 1;
            }
            return 0;
        }
        return dfs(numbers, n + 1, sum + numbers[n], target) + dfs(numbers, n + 1, sum - numbers[n], target);
    }
}
```

### 네트워크 (2번)

> 효율성이 좋지 않다.
>
> 크루스칼 알고리즘을 비슷하게 사용하려고 했지만 변경사항이 있을 시 visit을 for 문으로 모두 확인하고 변경해야 하기 때문에.. (코드 확인)

```java
import java.util.*;
class Solution {
    public int solution(int n, int[][] computers) {
        int answer = 1;
        int visit[] = new int[n];
        for (int i = 0; i < n; i++)
            visit[i] = i;
        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < i; j++)
            {
                if (computers[i][j] == 1)
                    visit = check_com(visit, i, j, n);
            } // small for end
        } // big for end
        Arrays.sort(visit);
        for (int i = 0; i < n - 1; i++)
        {
           // System.out.println(visit[i]);
            if (visit[i] != visit[i + 1])
                answer++;
        }
       // System.out.println(visit[2]);
        return answer;
    } // solution end
    
    private int[] check_com(int[] visit, int f_n, int s_n, int n)
    {
        // i (f_n) > j (s_n)
        if (visit[f_n] < visit[s_n])
            visit[f_n] = visit[s_n];
        else
        {
            int temp = visit[s_n];
            for (int i = 0; i < f_n; i++)
            {
                if (visit[i] == temp)
                    visit[i] = visit[f_n];
            }
        }
        return visit;
    }
}
```

```java
class Solution {
    public int solution(int n, int[][] computers) {
        int answer = 0;
        boolean[] chk = new boolean[n];
        for(int i = 0; i < n; i++) {
            if(!chk[i]) {
                dfs(computers, chk, i);
                answer++;
            }
        }
        return answer;
    }
    void dfs(int[][] computers, boolean[] chk, int start) {
        chk[start] = true;
        for(int i = 0; i < computers.length; i++) {
            if(computers[start][i] == 1 && !chk[i]) {
                dfs(computers, chk, i);
            }
        }
    }
}
```
